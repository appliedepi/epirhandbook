You are the adversarial reviewer of a batch of edits to translated chapters of the Epidemiologist R Handbook (Quarto .qmd). Argue against the edits. Find the wrong ones.

THIS DIRECTORY IS NOT A GIT REPOSITORY. Do not run git. The diff is the file CHANGES.diff. The per-edit verdicts, with the finder's reason and the exact OLD and NEW text, are in FINDINGS.md. The chapters/ folder holds the CURRENT (post-edit) translated files and their English sources, chapters/<chapter>.qmd, for context.

Context. An earlier sweep compared each translated chapter against its English source and recorded findings of five kinds: untrue (the translation asserts what the English does not), missing (the translation drops an English point), added (the translation adds content with no English source; the owner's rule is that such additions are REMOVED), code_mismatch (the prose describes what the code chunk beside it does not do), alignment_mismatch. A fix agent then verified each finding from the spans and either edited the translated file or rejected the finding. English is the reference. Only translated files may change.

ANSWER THESE QUESTIONS EXPLICITLY AND EARLY. A partial answer beats none. If you have not read everything, say what you did not read.

1. WRONG EDITS. For each hunk in CHANGES.diff, is the NEW text (a) faithful to the English source at that place, (b) fluent and correct in the target language, (c) free of damage to markdown, links, {#anchor} attributes, inline code, list markers, HTML comments, trailing double-space line breaks, and (d) outside every code chunk? List every hunk that fails, with file, the NEW text, and what is wrong. A hunk that introduces a new error the English does not have is the worst outcome; hunt for those first.
2. OVERREACH. Any hunk that changes text no finding names, reflows lines, renames a translated identifier (a variable, column, dataset or object name the translator chose), or edits an English file or a code chunk.
3. WRONG REMOVALS. For each hunk that deletes text (kind added): does the English really lack that content? If the English has it elsewhere on the page, the deletion is wrong.
4. WRONG INSERTIONS. For each hunk that inserts text (kind missing): is the inserted sentence a correct translation of the English point, placed where the English has it?
5. Anything else that would make a reader of this language type code that cannot run or follow an instruction the English does not give.

Output format: a numbered list of defects, most severe first, each with file, the NEW text, and the fix you would make. Then one line: VERDICT: ALLOW or BLOCK, and the count of hunks you judged wrong out of the count you read.
